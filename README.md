# World History Map

An open-source, community-edited map of the world from about 3000 BCE to today.
Explore borders, rulers, thinkers, works and inventions period by period.

Status: version 1.0. See [CHANGELOG.md](CHANGELOG.md), [About page](https://omidhey.github.io/world-history-map/about.html) and [CHECKPOINTS.md](CHECKPOINTS.md) for progress and
[docs/roadmap.md](docs/roadmap.md) for the full plan.

## Run it locally (Windows)

Double-click `run_site.bat`, or:

```
python pipeline/build_site.py
cd site
python -m http.server 8000
```

then open http://localhost:8000. Opening `index.html` directly does not work,
because browsers block loading local data files from `file://`.

Live site: https://omidhey.github.io/world-history-map/

When a pull request is merged into `main`, GitHub Actions validates the records,
builds the site data and republishes the site. If validation fails, nothing is published.

## Updating the border data

```
npm install
python -m venv .venv
.venv/Scripts/pip install -r pipeline/requirements.txt
.venv/Scripts/python pipeline/download_borders.py
```

This downloads 14 snapshots into `raw/`, simplifies them with mapshaper into
`data/borders/`, applies the sourced corrections in `data/borders/overrides.json`
and rewrites `data/borders/manifest.json`. Why realms sometimes vanish between
snapshots, and what was corrected: [docs/vanished-realms.md](docs/vanished-realms.md). Sizes are in
[docs/data-notes.md](docs/data-notes.md).

## Folder layout

| Folder | Contents |
|---|---|
| `data/` | Source of truth, edited by contributors (one JSON file per record) |
| `pipeline/` | Python scripts: download, validate, build |
| `site/` | The web page. `site/data/` is generated, not edited |
| `docs/` | Decisions, schema, data notes, roadmap |
| `raw/` | Downloads (git-ignored) |
