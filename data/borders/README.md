# Border snapshots: credit and license

The `world_*.geojson` files here are derived from
[historical-basemaps](https://github.com/aourednik/historical-basemaps) by A. Ourednik,
pinned to commit `da7a4b7` (see `pipeline/download_borders.py`).

**License: GPL-3.0-or-later**, as for the rest of the repository (see the README's
Licensing section). The source is published under the GPL v3; the full text is in
[LICENSE](../../LICENSE) at the repository root. The source's author describes the data as work in progress, and
borders are approximate.

What this project changed:

- Simplified with mapshaper 0.7.90 (`-simplify 10% keep-shapes`, each realm split into its
  parts first so small islands survive). Sizes in [docs/data-notes.md](../../docs/data-notes.md).
- Applied the sourced corrections in `overrides.json`. Each one has a note and at least one
  source. See [docs/vanished-realms.md](../../docs/vanished-realms.md).
- Land the source leaves unnamed keeps its last recorded realm, marked as carried forward
  (`pipeline/carry_forward.py`).

`manifest.json` lists the snapshots. All files here are generated by
`pipeline/download_borders.py`; correct them by changing `overrides.json` or the pipeline,
not by hand-editing the GeoJSON.
